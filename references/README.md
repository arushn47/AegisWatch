# References

Non-runtime reference material for the AegisWatch project.

## `stitch-design-explorations/`

Early design explorations for the **Stitch "Orbital Telemetry & Crisis Operations"** visual direction that the app's tactical mission-control aesthetic is built against.

These are **not part of the built application**. The app itself (`frontend/`) implements the final Stitch-derived design tokens (see `frontend/tailwind.config.js` and `docs/Design.md`). This folder is preserved as design history / reference only.

## `legacy-disasterwatch-prd.md`

The original v1.0 **draft** PRD, written under the project's former name (DisasterWatch) and an early architecture (Spring Boot / PostGIS / Redis / SSE / Gemini) that the shipped app does not use. Superseded by the approved baseline at `docs/PRD.md`; kept here as history, not as a specification.
